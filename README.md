## Overview

This project demonstrates a simple R-based data analysis workflow using
a **synthetic sales dataset**. The documentation is organized so that
another user can quickly understand the project's purpose, requirements,
workflow, and expected outputs.

## Project Purpose

The project is designed to:

-   Import a synthetic dataset into R.
-   Inspect the structure and quality of the data.
-   Prepare the data for analysis.
-   Summarize selected variables.
-   Present the workflow in clear, reproducible documentation.
