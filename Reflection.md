# Reflection Questions

## 1. What did you learn from completing the Markdown Buddy assignment?

I learned how to use Markdown to organize and format information. I also learned how Markdown files can be used in a project and how to work with different formatting options.

## 2. What challenges did you face while completing this assignment, and how did you solve them?

At first, some parts of Markdown were new to me and I was not sure how to format everything correctly. I followed the assignment instructions and practiced the different Markdown commands until I understood how they worked.

## 3. How can Markdown be useful in your future data science projects?

Markdown can help me create clear and organized documentation for my data science projects. I can use it to explain my work, write notes, describe my code and results, and make my projects easier for other people to understand.
